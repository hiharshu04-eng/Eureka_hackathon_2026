# EurekaHacks 2026 — Official Hackathon Landing Page

> *"Never stop learning, never stop exploring. It's Eureka every day."*

This repository contains the official frontend web application designed for **EurekaHacks 2026**, organized by **Eureka Club, VIT Bhopal University**. Built as part of the Technical Recruitment Round 2 evaluation (Batch 2026).

---

## 📌 Project Overview

EurekaHacks is an intensive 36-hour campus-wide hackathon designed for builders, designers, and developers. This web portal serves as the primary landing page to communicate schedule details, focus tracks, eligibility guidelines, and direct registration pipelines.

### Key Highlights
- **Mandated Design System**: Configured strictly with the specified Eureka Club root palette and typography (`Plus Jakarta Sans` & `JetBrains Mono`).
- **Live Event Countdown**: Real-time JavaScript clock dynamically computing remaining time until the opening ceremony.
- **Interactive FAQ Engine**: Handcrafted accordion component built with vanilla DOM event handling.
- **Direct Portal Integration**: One-click action triggers directing participants straight to the verified technical registration form.
- **Responsive Architecture**: Flexbox and CSS Grid layouts optimized across mobile, tablet, and desktop viewports.
